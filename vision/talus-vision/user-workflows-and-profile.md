# User Workflows & Profile

User activity within the application is continuously tracked. The interface includes two user-specific sections:

## Profile Section (top-right corner)

- Shows the number of draft workflows currently in progress.
- Displays how many workflows have been deployed using the connected wallet.
- Additional profile features will be introduced in future versions after Devnet.

## Deployments Navigation Button (left of the profile button)

This button redirects users to the **Deployments** page, which contains two tabs:

### My Workflows

Displays workflows that are still being edited in the playground.  
Clicking a workflow loads it back into the playground for continued editing.

### Deployments

Shows workflows that have been deployed on-chain.  
Clicking a workflow opens it in **View Mode** within the playground, allowing users to inspect and interact with the deployed version.
