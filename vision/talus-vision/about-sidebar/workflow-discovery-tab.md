# Workflow Discovery Tab

This tab provides on-chain access to all deployed workflows. Users can browse and interact with workflows created by others.

Key capabilities include:

- **Featured Workflows:** Highlights workflows commonly executed by the community.
- **All User-Created Workflows:** Full list of workflows deployed by Nexus users.
- **Workflow Details:** Shows tools used, deployment date, and ownership information.
- **Template Reuse:** Option to load any workflow as a template and redesign it in the playground.
- **Quick Execution:** Run workflows directly without modification.
