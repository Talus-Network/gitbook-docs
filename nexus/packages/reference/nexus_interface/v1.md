# `nexus_interface::v1`

`v1` no longer exposes the retired witness announcement path for active package authoring. It remains as a compact compatibility module for shared-object reference and interface package configuration values used by verifier metadata and historical decoding.

Primary surfaces:

- `InterfacePackageConfig`: persisted shared-object reference configuration.
- `new_interface_package_config`: builds a config from shared object refs.
- ``: builds an immutable shared object reference.

New Talus Protocol execution should use [`nexus_interface::tap`](tap.md). Verifier packages should use [`nexus_interface::verifier_v1`](verifier_v1.md) for proof and result envelopes.
